# java-calculator-precourse

## 기능 목록
### - 입출력
- [x] 문자열을 입력 받는다.
- [x] 계산된 결과를 출력한다.

### - 기능 
- [x] 빈 문자열을 받으면 결과를 0으로 처리한다.
- [ ] 입력 문자열에서 구분자를 기준으로 분리한다.
  - [ ] 기본 구분자는 쉼표(,) 또는 콜론(:)이다. 
  - [ ] 기본 구분자 또는 커스텀 구분자가 아닌 구분자는 허용되지 않는다.
- [ ] 구분자를 커스텀 할 수 있다.
  - [ ] 문자열 앞부분의 "//"와 "\n" 사이에 위치하는 문자를 커스텀 구분자로 사용한다.
  - [ ] 커스텀 구분자로 공백과 숫자는 허용하지 않는다.
- [ ] 분리된 문자열을 정수로 변환한다.
  - [ ] 숫자가 아닌 값은 허용하지 않는다.
  - [ ] 음수는 허용되지 않는다.
- [ ] 각 숫자를 더한다.
